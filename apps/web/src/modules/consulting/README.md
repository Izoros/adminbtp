# Module consulting

Module reserve a l'expertise ingenieur, architecte HMONP et missions de conseil.

## Mode donnees

- priorite a Supabase si le contexte serveur et les donnees reelles sont disponibles
- repli automatique sur un jeu de demonstration si la base n'est pas joignable ou vide

## Ecritures minimales

- creation d'une demande expert depuis la page `consulting`
- aucune dependance au core en dehors du client Supabase serveur deja expose
