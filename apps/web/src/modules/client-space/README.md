# Module client-space

Module reserve a l'espace client simplifie avec filtrage strict par organisation.

## Mode donnees

- affichage base sur Supabase si des acces client reels existent
- repli demo pour conserver un parcours visualisable sans dependance externe

## Ecritures minimales

- ajout de commentaire sur un item visible depuis la page `client-space`
- filtrage strict des items et commentaires avant ecriture
